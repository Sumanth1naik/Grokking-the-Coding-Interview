# Happy Number
**Problem Statement**  
Any number will be called a happy number if, after repeatedly replacing it with a number equal to the sum of the square of all of its digits, leads us to the number 1. All other (not-happy) numbers will never reach 1. Instead, they will be stuck in a cycle of numbers that does not include 1.

Given a positive number n, return true if it is a happy number otherwise return false.

**Examples :**
```
Input: n = 19
Output: true
Explanation:
19 = 1² + 9² = 82
82 = 8² + 2² = 68
68 = 6² + 8² = 100
100 = 1² + 0² + 0² = 1
Since the sequence reaches 1, return true.
```
```
Input: n = 20
Output: false
Explanation:
20 = 2² + 0² = 4
4 = 4² = 16
16 = 1² + 6² = 37
37 = 3² + 7² = 58
58 = 5² + 8² = 89
89 = 8² + 9² = 145
145 = 1² + 4² + 5² = 42
42 = 4² + 2² = 20
The sequence enters a cycle without reaching 1, so return false.
```

# Approach
1. We can use the **Fast and Slow Pointers** technique to detect a cycle in the sequence of numbers generated by repeatedly replacing the number with the sum of the squares of its digits. The idea is to have two pointers traverse the sequence at different speeds. The slow pointer moves one step at a time, while the fast pointer moves two steps at a time. If there is a cycle, the fast pointer will eventually meet the slow pointer.
2. If the sequence reaches 1, we can return true. If a cycle is detected
, we can return false.

#
**Time Complexity:** O(log n), where n is the input number. In the worst case, we may have to traverse all numbers in the sequence to detect a cycle or reach 1.  
**Space Complexity:** O(1), as we are using only two pointers regardless of the input size.
